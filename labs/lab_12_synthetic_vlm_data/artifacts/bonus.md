# Мини-исследование: переносится ли счёт фигур на реальные объекты

**Гипотеза.** Замороженные признаки ResNet18 на геометрических сценах не переносят навык «2 или 3 объекта» на реальные фотографии:
классификатор только на синтетике работает на дополнительных реальных изображениях не лучше доли большего класса.

**Протокол.** Дополнительные реальные изображения — 24 фото PixMo-Count validation (классы 2/3), не входящие
ни в real train, ни в отложенный test (проверка по SHA256). Бюджет 24 обучающих примеров, 20 seed,
логистическая регрессия на тех же признаках. Правило (задано до просмотра): подтверждено, если accuracy synthetic-only ≤ majority + 0,05.

| обучение | accuracy на доп. реальных (среднее по seed) |
|---|---:|
| только синтетика (0/100) | 0.487 |
| только реальные (100/0) | 0.458 |
| majority baseline | 0.500 |

**Итог по правилу: гипотеза подтверждена.** Сравнение с основным экспериментом — в README работы.
