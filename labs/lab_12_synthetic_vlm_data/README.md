# Лабораторная работа №12. Генерация синтетического датасета для VLM

**Дата:** 31.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Построить конвейер «спецификация сцены → рендер → VLM-проверка → фильтрация», сохранить provenance каждого примера и проверить, помогает ли синтетика downstream-модели на полностью реальном test. Задача — счёт объектов (2 или 3). Синтетика — геометрические фигуры, реальные данные — фотографии PixMo-Count. Это междоменный эксперимент, а не тест распознавания фигур.

## Данные

- **Синтетика:** 150 сцен (по 50 с 1, 2 и 3 фигурами), 224×224, рендер PIL без перекрытий. 20 % — редкие случаи: мелкие фигуры или низкий контраст. Seed, спецификация, путь и provenance — в `synthetic_manifest.jsonl`.
- **Реальные:** PixMo-Count (allenai, ODC-BY-1.0; права исходных фото Flickr могут отличаться). Human-verified validation — 24 фото для обучения, официальный test — 12 фото, классы 2/3 поровну. Скачиваются загрузчиком `open_real_scenes.py`, в репозиторий не добавляются. Манифест с URL и контрольными суммами — `real_manifest.json`.

## Модели

- VLM-проверка: Qwen2.5-VL-3B-Instruct, bitsandbytes NF4 на Apple MPS, greedy.
- Downstream: замороженные признаки ResNet18 (ImageNet) + логистическая регрессия (C = 0,1), бюджет 24 примера, 20 seed.

## Результаты

| этап | результат |
|---|---|
| согласие VLM с разметкой генератора | 149 / 150 (99,3 %), редкие случаи — без ошибок |
| дубликаты по пикселям | 0 |
| принято в датасет | 149 сцен (`accepted.jsonl`) |

| real / synthetic (24 примера) | accuracy на реальном test (12 фото) |
|---|---:|
| 100 / 0 | 0,333 |
| 75 / 25 | 0,363 ± 0,071 |
| 50 / 50 | 0,421 ± 0,110 |
| 25 / 75 | 0,454 ± 0,180 |
| majority baseline | 0,500 |

**Бонус:** на 24 дополнительных реальных фото synthetic-only даёт 0,487, real-only — 0,458 (majority 0,500). Отсутствие переноса подтверждено по заранее заданному правилу (`artifacts/bonus.md`).

## Анализ

- VLM надёжно проверяет простую синтетику: единственная ошибка — «4» вместо 3 на обычной сцене.
- Ни одна смесь не выше случайного угадывания. Real-only (0,333) запоминает признаки сцен train, которые на test работают в обратную сторону. Синтетика только приближает модель к константному ответу.
- Глобальный pooling ResNet18 почти не кодирует число одинаковых объектов, а 24 примеров слишком мало, чтобы это компенсировать. Добавляется и большой domain gap между фигурами и фотографиями.
- На 12 test-изображениях одно изображение — 8,3 п. п., поэтому различия смесей статистически ненадёжны.

## Выводы

1. Конвейер генерации с provenance и VLM-фильтрацией работает и воспроизводим по seed.
2. Синтетические геометрические сцены не переносят счёт на реальные объекты при замороженных глобальных признаках: полезной доли синтетики в этой постановке нет.
3. Для пользы от синтетики нужны реалистичные объекты и модель с пространственным выходом (детекция, density map).
