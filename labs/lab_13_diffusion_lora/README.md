## Вычислительный профиль

Данные скачиваются автоматически при первом запуске: 28 реальных фотографий бабочек из [Wikimedia Commons](https://commons.wikimedia.org/) через [`download_open_data.py`](download_open_data.py). Скрипт проверяет **индивидуальные** `imageinfo.extmetadata.LicenseShortName=CC0` и ссылку [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) для каждого изображения; записывает URL страницы, заявленного автора, исходный SHA1 и SHA256 загруженной миниатюры в `metadata.jsonl`. Проверен реальный запуск на 28 RGB JPEG. Изображения и метаданные не добавляются в Git. Нужна сеть и Pillow; `CV_LORA_DATA` может указать иной каталог с уже подготовленным metadata.jsonl. Пользовательские файлы не требуются. Статус CC0 отражает опубликованные Commons метаданные, а не независимую юридическую экспертизу прав на каждое фото.

Stable Diffusion 1.5 LoRA, замороженная основа и FP16 autocast с обучаемыми параметрами LoRA в FP32; короткий режим использует 256 px и один optimizer update. Для полного режима нужны CUDA, достаточная VRAM, `torch`, `torchvision`, `diffusers`, `transformers`, `accelerate`, `peft`, `safetensors`, `Pillow`; без SDXL/FLUX.

Начните с `FAST_DEV_RUN=True`. Сокращённый режим предназначен для проверки программы и не заменяет полный эксперимент. Результаты и контрольные точки сохраняйте в `artifacts/` и переносите в постоянное хранилище до завершения сессии Colab.
