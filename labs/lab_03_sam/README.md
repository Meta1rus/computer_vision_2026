# Лабораторная работа №3. Foundation models для сегментации: SAM

**Дата:** 25.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Получить маски SAM по точке и по рамке, сравнить их с supervised-моделью на тех же отложенных изображениях и проверить, исправляет ли маски SAM лёгкий корректор, обученный на trainval.

## Данные и модели

- Oxford-IIIT Pet (CC BY-SA 4.0): 200 изображений official test (seed 42), длинная сторона ≤ 512 px. GT — класс «животное» trimap, полоса границы в IoU не учитывается.
- Подсказки из GT имитируют разметчика: точка — пиксель животного у медианы координат, рамка — bbox животного.
- SAM ViT-B (`facebook/sam-vit-base`), заморожен; из трёх кандидатов выбирается маска с максимальной предсказанной IoU.
- Supervised baseline — LRASPP MobileNetV3, 10 эпох на 3 680 изображениях trainval.
- Корректор — U-Net по RGB и вероятности SAM, 600 изображений trainval, 25 эпох.

## Результаты

| метод | mean IoU | median IoU | IoU < 0,8 |
|---|---:|---:|---:|
| SAM, точка | 0,815 | 0,989 | 25 % |
| SAM, рамка | 0,967 | 0,994 | 3 % |
| SAM, рамка + корректор | 0,970 | — | 3,5 % |
| LRASPP (supervised) | **0,974** | — | 2 % |

- SAM с рамкой и LRASPP значимо не различаются (Уилкоксон, p = 0,24).
- Корректор улучшает 145 масок из 200 при среднем приросте +0,003 (p = 3·10⁻¹²).
- При идеальном выборе одного из трёх кандидатов точка дала бы 0,958, рамка — 0,978.

**Бонус:** точка с максимальным расстоянием до края вместо медианной — 0,800 против 0,815, p = 0,88, разницы нет (`bonus_points.json`).

## Анализ ошибок

- **Точка:** 32 провала из 200 (IoU < 0,5), в 26 из них SAM выделил часть животного — пятно, язык, нос. В 25 провалах маска с IoU ≥ 0,8 была среди кандидатов, но получила меньшую оценку SAM.
- **Рамка:** не тот кандидат (ящик под кошкой, подушка под собакой), костюм собаки, которого нет в GT, и морда на весь кадр с затеканием в фон (`box_failures.png`).
- **Корректор:** убирает шум и протечки (до +0,08), но сглаживает тонкие уши и лапы (до −0,03) и не уменьшает долю грубых ошибок.
- **Разметка:** в 22 из 200 trimap класс «граница» проведён и по краям кадра. Рамка по «животное + граница» охватывала тогда весь кадр, SAM возвращал фон, и средний IoU в первой версии был 0,936. Поэтому рамка строится только по животному.

## Выводы

1. Рамка — достаточная подсказка: SAM без дообучения сравним с supervised-моделью, обученной на 3 680 масках.
2. Одна точка ненадёжна из-за выбора кандидата, а не из-за качества сегментации.
3. Лёгкая адаптация по 600 примерам полирует контуры, но не исправляет грубые ошибки.
