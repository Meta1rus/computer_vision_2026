# Лабораторная работа №11. Alignment VLM по предпочтениям (DPO)

**Дата:** 31.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Дообучить SFT-адаптер Qwen2.5-VL-3B из работы 9 методом DPO на парах предпочтений «верный ответ против неверного». Сравнить исходную модель, SFT (reference) и DPO (aligned) автоматически и слепой ручной оценкой.

## Данные и модель

- Пары из подвыборки ScienceQA работ 9–10 (CC-BY-SA-4.0): chosen — верная буква, rejected — следующий по кругу вариант. 512 пар train, слепой тест — 64 вопроса ID-теста, пересечений по ID и хешу изображения нет (`pair_audit.json`).
- Qwen2.5-VL-3B-Instruct, NF4 (bitsandbytes) на MPS. Reference и стартовая политика — SFT-адаптер работы 9.
- Собственная реализация DPO: log-prob ответа по его токенам, loss −log σ(β·Δ), β = 0,1, AdamW lr 5e-6, 40 шагов × 8 пар. Reference заморожен.

## Результаты

| политика | EM (64 вопроса) | формат «одна буква» | варианты вне списка | win rate aligned |
|---|---:|---:|---:|---:|
| foundation | 0,828 | 0,906 | 1 | 0,563 |
| reference (SFT) | 0,891 | 1,000 | 0 | 0,508 |
| aligned (DPO) | **0,906** | 1,000 | 0 | — |

- DPO: loss 0,693 → 0,613, margin до 1,7–2,1; 50 минут обучения.
- Слепая оценка (`blind_judgements.jsonl`, ключ — `blind_key.json`): в 50 вопросах из 64 ответы совпали, в 12 различающихся лучший ответ определён решением вопроса. Все 12 решений совпали с ключом ScienceQA. Два вопроса без текста отрывка нельзя решить по входу.

**Бонус** (`bonus.md`): позиционного сдвига после DPO нет. Доля ответов «следующая за верной» одинакова (0,125), TV-расстояние распределений букв 0,016 — гипотеза не подтверждена.

## Анализ ошибок

- DPO отличается от SFT лишь в одном вопросе: выбрал акулу как рыбу (верно), а SFT выбирал лягушку.
- 6 ошибок aligned те же, что у SFT:
  - сила магнитов в двух парах;
  - концентрация частиц;
  - многоклеточность Rafflesia;
  - притяжение магнитов;
  - два вопроса «погода или климат» без текста отрывка — загрузчик курса не передаёт поле hint ScienceQA.
- Половина преимуществ над исходной моделью — формат («B.» вместо «B», несуществующий вариант C). Этот выигрыш дал SFT, а не DPO.

## Выводы

1. DPO на парах «верная буква против соседней» почти не меняет SFT-политику: она уже разделяет такие пары с запасом Δlog p ≈ 5,6, поэтому градиент мал.
2. Выигрыш над исходной моделью (+7,8 п. п. EM, 100 % формат) обеспечен SFT. DPO его сохраняет.
3. Для заметного эффекта DPO нужны трудные пары из собственных ошибок модели.
