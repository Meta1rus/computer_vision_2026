# Лабораторная работа №7. Автоматическая разметка изображений с помощью VLM

**Дата:** 27.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Разметить изображения VLM по строгой JSON-схеме (класс, подпись, флаг неуверенности), оценить качество классов на отложенном test, проверить подписи экспертным аудитом и сравнить классификатор, обученный на метках VLM, с обученным на ручных метках.

## Данные и модель

- CIFAR-10 (официальный train/test): стратифицированно 400 изображений train (по 40 на класс) и 200 test (по 20). Манифест — `images.jsonl`, эталонные метки VLM не передаются.
- Qwen2.5-VL-3B-Instruct, fp16 на Apple MPS. Схема — pydantic, класс только из 10 названий. Первая попытка greedy, до двух повторов с семплированием. 600 изображений за 97 минут.

## Результаты

| показатель | значение |
|---|---:|
| валидный JSON (coverage) | 1,000 (3 повтора на 600) |
| accuracy классов, test | **0,935** |
| accuracy при confidence ≥ 0,8 (78 % test) | 0,987 |
| подписи: верно / частично / неверно (аудит 30) | 80 % / 13 % / 7 % |
| подписи с галлюцинациями | 17 % |
| downstream: ручные метки / метки VLM | 0,765 / 0,730 |

Слабее всего класс frog (recall 0,75). Шум VLM-меток на train — 11,75 %. Флаг uncertain модель ставит в 1 % случаев, поэтому для фильтрации он бесполезен в отличие от confidence по первому токену класса.

**Бонус** (`bonus.md`): на 100 новых изображениях при confidence ≥ 0,95 точность 1,000, ниже порога — 0,633. Но ошибки сосредоточены не в похожих парах классов (4 из 11), а в запасном классе truck (6 из 11), поэтому заранее заданное правило гипотезу не подтвердило.

## Анализ ошибок

- **Классы:** frog → cat/dog/bird, deer → dog/horse, ship → truck/airplane, automobile → truck.
- **Подписи:**
  - птица названа самолётом, парусник — грузовиком;
  - стоящему самолёту приписан полёт, живой лошади — «статуя», самосвалу — ковш погрузчика.

  При 32×32 модель достраивает невидимые детали.

## Выводы

1. Авторазметка CIFAR-10 моделью Qwen2.5-VL-3B даёт 93,5 % точности и полностью валидный JSON при строгой схеме с повторами.
2. Для отбора разметки на ручную проверку нужен confidence по распределению токенов, а не самоотчёт модели.
3. Шум меток около 12 % стоит downstream-классификатору 3,5 п. п.; подписи требуют выборочного аудита.
