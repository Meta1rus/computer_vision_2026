## Входные данные и вычисления

CIFAR-10 train/test загружается в notebook; полный прогон требует GPU и ручного аудита captions.

`FAST_DEV_RUN=True` — только smoke; для сдачи установите `False`, сохраните `artifacts/` в постоянном хранилище, зафиксируйте версии модели и библиотек. Данные и метрики не подменяются фиктивными примерами. CPU не является заменой GPU для VLM-обучения.

## Проверяемые артефакты

`artifacts/`: annotations.jsonl, quality.json, human_audit.jsonl, downstream.json. Приложите сведения об источнике данных, лицензии, конфигурации, времени и памяти, оценку на независимом test и разбор ошибок. Если обязательные входные данные отсутствуют, notebook завершается явной ошибкой.
