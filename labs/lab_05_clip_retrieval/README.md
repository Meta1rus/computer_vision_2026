# Лабораторная работа №5. CLIP: zero-shot-классификация и мультимодальный поиск

**Дата:** 26.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Сравнить текстовые шаблоны в zero-shot-классификации, построить поиск изображений по тексту, дообучить projection head по парам «изображение — подпись» и оценить accuracy и качество поиска до и после адаптации.

## Данные и модель

- OpenCLIP ViT-B-32, веса `laion2b_s34b_b79k` (MIT), энкодеры заморожены.
- CIFAR-10: 5 000 пар из официального train (по 500 на класс, подпись `a photo of a <класс>.`) — для обучения проекций; 1 000 других изображений train — validation; поисковый индекс — весь test (10 000).
- Шаблон для запросов выбирается по validation, test используется только для отчёта.

## Результаты

**Zero-shot:** лучший шаблон по validation — `a drawing of a {}.` (val 0,947, test 0,937); `a photo of a {}.` — 0,944/0,937; голое имя класса — 0,922/0,915; ансамбль 7 шаблонов — 0,943/0,935.

**Поиск и адаптация:**

| | test accuracy | mean precision@10 | mAP |
|---|---:|---:|---:|
| исходный CLIP | 0,937 | 0,95 | 0,857 |
| + две линейные проекции | **0,957** | **1,00** | **0,969** |

Проекции изображения и текста (512×512, тождественная инициализация) обучались cross-entropy изображения против всех 10 классовых прототипов: одинаковые подписи в батче не становятся ложными негативами. 30 эпох, AdamW, lr 1e-4.

Поклассовая динамика (`retrieval_deltas.json`): P@10 у dog 0,7 → 1,0, у automobile 0,8 → 1,0. AP у dog 0,66 → 0,94, у automobile 0,81 → 0,99, у horse 0,80 → 0,99; меньше всего вырос cat (0,84 → 0,89).

## Анализ ошибок

- Худший класс исходного поиска — dog: в top-10 две кошки и лошадь (`search_examples.png`); у automobile в top-10 попадают грузовики.
- Шаблон «рисунок» лучше «фото» на validation: CIFAR-картинки при увеличении до 224 px выглядят как размытые рисунки.
- Бонус: запрос «a red vehicle on a road» возвращает 10 красных машин и грузовиков, в основном на дороге (`bonus_retrieval.png`, без искусственной разметки).

## Выводы

1. Zero-shot CLIP — 93,7 % на CIFAR-10. Выбор шаблона даёт +2 п. п., выбирать его нужно по validation.
2. Линейная адаптация по классовым прототипам поднимает accuracy до 95,7 % и mAP с 0,86 до 0,97. Улучшение измерено на классовой релевантности, для произвольных описаний оно не проверялось.
