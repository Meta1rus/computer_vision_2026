# Лабораторная работа №8. Active learning и human-in-the-loop

**Дата:** 27.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Сравнить стратегии выбора объектов для разметки — random, entropy (uncertainty) и k-center (diversity) — при одинаковом бюджете, построить learning curves и разобрать ошибки на отложенном test.

## Данные и протокол

- `sklearn.datasets.load_digits` — 1 797 рукописных цифр 8×8 (UCI ML hand-written digits, CC BY 4.0).
- Стратифицированный test — 540 изображений (30 %), отложен до выбора стратегий. Train-pool — 1 257.
- Старт: по 2 размеченных объекта на класс (20). Затем 8 раундов по 20 запросов, итоговый бюджет 180 меток.
- **Разметчик — симулированный oracle:** истинная метка объекта pool открывается только после того, как стратегия выбрала объект. Источник каждой метки записан в журнале (`simulated_oracle`). Это воспроизводимая симуляция, а не ручная разметка.
- Модель — LogisticRegression(C=1) на пикселях, переобучается с нуля после каждого раунда.
- k-center обновляет расстояния до размеченного множества после каждого выбранного объекта.

## Результаты

| стратегия | AUC кривой accuracy(n) | accuracy при 180 метках |
|---|---:|---:|
| random (seed 42) | 0,862 | 0,926 |
| random, 10 seed | 0,850 ± 0,011 | 0,913 ± 0,011 |
| entropy | 0,781 | 0,926 |
| **k-center** | **0,899** | **0,941** |

AUC нормирована на ширину диапазона бюджета (то есть это средняя accuracy по кривой). Чувствительность к стартовому набору (5 разных initial): random 0,859 ± 0,018, entropy 0,835 ± 0,014, k-center 0,895 ± 0,004.

Кривые — `artifacts/learning_curves.png`.

## Анализ

- k-center выигрывает у random на всех бюджетах и достигает финальной точности random примерно на 100 метках вместо 180.
- Entropy на холодном старте проваливается после первого раунда (0,719 → 0,428): запросы концентрируются в нескольких трудных классах (в итоге 34 метки класса 8 против 11 у классов 0 и 6), и модель смещается. Random она догоняет только к 140–160 меткам.
- Ошибки финальной модели (32 из 540): 8→1, 1→8, 9→8, 6→8 — на сетке 8×8 тонкие штрихи сливаются.

## Бонус: избыточность энтропийного отбора

Гипотеза проверялась на MNIST (3 000 объектов в pool, 2 000 для оценки, PCA-50, 5 seed), test digits не использовался. Энтропийный пакет компактнее случайного (средняя попарная дистанция 8,1 против 9,1), entropy уступает random (AUC 0,678 против 0,725), а гибрид «top-100 по энтропии → k-center» восстанавливает большую часть потерь (0,718). Подробно — [`artifacts/bonus.md`](artifacts/bonus.md).

## Выводы

1. При равном бюджете разметки diversity-отбор надёжно лучше случайного: +0,049 AUC к среднему random.
2. Uncertainty sampling с очень маленьким стартом вреден: пакеты избыточны и разбалансированы по классам.
3. Рабочая схема — начинать с покрытия пространства (k-center или классово-сбалансированный отбор), потом переходить к uncertainty или гибриду.
