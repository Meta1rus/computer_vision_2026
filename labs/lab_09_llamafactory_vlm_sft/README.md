# Лабораторная работа №9. Fine-tuning VLM с помощью LLaMA-Factory

**Дата:** 28.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Дообучить Qwen2.5-VL-3B-Instruct отвечать на вопросы ScienceQA с изображением одной буквой (QLoRA SFT в LLaMA-Factory). Сравнить с исходной моделью на трёх отложенных тестах: ID, OOD и general.

## Данные и модель

- ScienceQA (Lu et al., NeurIPS 2022; CC-BY-SA-4.0). Train — 512 вопросов естественных наук 2–6 классов, validation — 64. Тесты по 64: ID (те же темы), OOD (естественные науки 7–8 классов), general (обществознание). Пересечений train с тестами по хешу изображения нет.
- LLaMA-Factory 0.9.5: NF4-база, LoRA rank 8 / α 16 на всех линейных слоях LLM, vision tower заморожен. 100 шагов × accumulation 16, lr 1e-4 cosine, seed 42. Конфигурация — `artifacts/sft.yaml`.
- Оценка — exact match буквы, greedy, ответ с лишним символом считается ошибкой.

## Результаты

| тест | base | SFT | Δ | валидный формат base → SFT |
|---|---:|---:|---:|---:|
| ID | 0,828 | **0,891** | +6,3 п. п. | 0,906 → 1,000 |
| OOD | 0,578 | **0,719** | +14,1 п. п. | 0,984 → 1,000 |
| general | 0,875 | 0,875 | 0 | 1,000 → 1,000 |

- Обучение заняло 231 минуту на MPS, параллельно с другими задачами.
- Train loss: 0,208 → 0,111. Минимум validation loss — на 40 шаге (0,111), к 100 шагу он немного вырос (0,115).

**Бонус** (`bonus.md`): гипотеза о сдвиге ответов к частой букве B формально подтверждена (доля 0,312 → 0,516 при реальной 0,500), но эффект в основном объясняется форматом base: 7 ответов «B.» не засчитаны как «B». С ними доля base — 0,42, а SFT превышает реальную долю всего на один ответ.

## Анализ ошибок

- На ID 5 из 8 исправлений после SFT — исправленный формат («B.» → «B»). Содержательно модель почти не изменилась.
- На OOD исправлено 12 ответов (формат — только 1). SFT помог в смежной теме более высокого уровня.
- Ни base, ни SFT не решают:
  - карты и обмен в general — все 8 ошибок приходятся на одни и те же вопросы у base и SFT;
  - генетику (решётка Пеннета);
  - планирование эксперимента;
  - магниты.
- Два вопроса «погода или климат» нельзя решить по входу: загрузчик курса не передаёт текст отрывка (поле hint ScienceQA). Base здесь угадала, SFT — нет.

## Выводы

1. QLoRA SFT за 100 шагов дал 100 % валидный формат и прирост на ID (+6 п. п.) и OOD (+14 п. п.).
2. Прирост на ID — в основном формат, а не знания. На другой предмет (general) SFT не переносится.
3. Улучшение ID не гарантирует улучшения OOD: переносится то, что общее у задач (формат, чтение диаграмм), но не предметные знания.
