# Лабораторная работа №14. Управляемая генерация изображений: ControlNet Canny

**Дата:** 31.10.2026
**Ноутбук:** [student.ipynb](student.ipynb) — выполнен полностью, `FAST_DEV_RUN = False`

## Постановка

Генерировать рукописные цифры по контурам Canny реальных изображений MNIST через SD 1.5 + ControlNet. Изучить влияние силы контроля и CFG на соответствие контуру, тексту и разнообразие. Проверить, помогает ли синтетика классификатору на реальном test.

## Данные и модели

- MNIST: 200 изображений train (по 20 на класс) — источник контуров и реальная обучающая выборка; test — официальный (10 000).
- Контур: увеличение до 512 px, бинаризация, Canny (776–2 200 пикселей на контур).
- SD 1.5 + `lllyasviel/sd-controlnet-canny`, UniPC 20 шагов, fp16 на MPS. Сетка: baseline без контроля, control scale {0,6; 1,2} × CFG {4; 9} — 1 000 изображений, общий seed для всех настроек одного контура.
- Метрики: edge F1 контуров с допуском 4 px (основная — после растяжки контраста), CLIP-соответствие тексту, внутриклассовое CLIP-разнообразие.

## Результаты

| настройка | edge F1 (контраст) | CLIP текст | разнообразие |
|---|---:|---:|---:|
| baseline без контроля | 0,098 | 0,339 | **0,381** |
| scale 0,6, CFG 4 | 0,516 | 0,312 | 0,326 |
| scale 0,6, CFG 9 | 0,600 | **0,344** | 0,315 |
| scale 1,2, CFG 4 | 0,737 | 0,295 | 0,264 |
| scale 1,2, CFG 9 | **0,778** | 0,312 | 0,248 |

| классификатор (500 шагов) | accuracy на test |
|---|---:|
| 200 реальных | **0,926** |
| 200 реальных + 200 синтетических (scale 1,2, CFG 9) | 0,923 |
| только синтетика | 0,716 |

Генерация 800 управляемых изображений заняла 113 минут (8,5 с на изображение).

**Бонус** (`bonus_filtering.json`): если оставить только синтетику, которую real-only классификатор относит к нужному классу (37,5 %), real+synthetic даёт 0,929 против 0,923 без фильтрации. Эффект в нужную сторону, но мал.

## Анализ ошибок

- **Ошибки, найденные и исправленные:**
  - В первой версии контуры почти пустые (18–76 пикселей): Canny по плавно увеличенной цифре не проходил пороги. Классификатор на такой синтетике давал 0,109.
  - Edge F1 без нормализации контраста давал 0 у 39–84 % генераций с серой цифрой на сером фоне, даже когда форма совпадала.
- **Худшие случаи после исправления:**
  - одна настоящая неудача — при слабом контроле и CFG 4 контур «2» проигнорирован;
  - остальные — тонкая обводка контура, которую не видит Canny, и цветная заливка с низким яркостным контрастом.
- **Нарушение prompt:** в большинстве генераций цифра тёмная на светлом фоне, а не белая на чёрной.

## Выводы

1. ControlNet Canny при корректных контурах повышает структурное соответствие с 0,10 до 0,78.
2. Сильный контроль (scale 1,2) повышает структурное соответствие, но снижает разнообразие и соответствие тексту.
3. Синтетика из тех же 200 контуров сама несёт информацию о классе (0,716), но не улучшает классификатор на этих же реальных данных.
4. Метрику структуры надо проверять на худших случаях: фиксированный порог Canny без нормализации контраста искажает выбор настройки.
